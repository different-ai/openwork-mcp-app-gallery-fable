# OpenWork MCP Apps Example Gallery (fable candidate)

Status: implementation in progress. This repository does not yet serve any
working endpoint; no functionality claim is made by this bootstrap commit.

This repository is one of three isolated benchmark candidates implementing the
Hosted MCP Apps Example Gallery: a small public, Vercel-deployable service that
hosts a curated set of the official Model Context Protocol MCP Apps examples as
remote Streamable HTTP MCP servers, plus a gallery page with a **Copy MCP URL**
action per example.

This project is an independent hosted adaptation of official examples from
[`modelcontextprotocol/ext-apps`](https://github.com/modelcontextprotocol/ext-apps).
It is not an official Model Context Protocol service and is not hosted or
endorsed by the Model Context Protocol project.

- Gallery-owned code license: Apache-2.0 (see `LICENSE`).
- Copied upstream example code keeps its own notices: see
  `THIRD_PARTY_NOTICES.md`.
- Default and release branch: `forward`.
- Implementation label: `fable`.

A complete README with usage, endpoints, and reproduction instructions lands
with the implementation pull request.
